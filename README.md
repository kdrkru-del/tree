# Зеленый Срез

Отдельный статический проект многостраничного сайта компании для заявок на спил, обрезку деревьев, удаление пней и расчистку участков в Москве и Московской области.

## Запуск

```bash
npm run build
npm run serve
```

Готовые файлы создаются в `dist/`.

## Что редактировать перед публикацией

- Контакты, домен, реквизиты и интеграции: `src/data.mjs`.
- Стили: `src/styles.css`.
- Логика формы, цели и резервное сохранение: `src/app.js`.

## Интеграции

В `src/data.mjs` заполните:

- `baseUrl` - реальный домен для canonical и sitemap.
- `phone`, `phoneHref`, `email`, `telegramUrl`, `messengerUrl`.
- `metrikaId` - номер счетчика Яндекс.Метрики.
- `leadEndpoint` - HTTPS-адрес защищенного обработчика, который передает заявку в Telegram.
- `novofonScriptUrl` - скрипт или виджет телефонии Novofon, если он используется.

Форма собирает UTM-метки, страницу входа, выбранную услугу, населенный пункт, контакты и фотографии. Готовый обработчик находится в `worker/`; инструкция по его развертыванию — в `worker/README.md`. Если `leadEndpoint` еще не указан или временно недоступен, сайт открывает Telegram с заполненным сообщением и честно просит посетителя нажать «Отправить».

Токен Telegram-бота и идентификатор чата должны храниться только в секретах Worker. Их нельзя добавлять в исходники или готовые файлы сайта.

## Важно

На сайте намеренно нет вымышленных отзывов, фиктивных офисов, ложных цен и неподтвержденных обещаний. Блоки работ и отзывов подготовлены под реальные материалы.
