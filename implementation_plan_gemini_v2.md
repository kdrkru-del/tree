# План изменений (Implementation Plan v2)

## 1. P0 (Критичные изменения перед запуском рекламы)

### 1.1 Интеграция Яндекс Метрики
- **Приоритет:** P0
- **Доказательство:** Переменная `metrikaId` пуста в исходном коде, нет отслеживания заявок (`src/data.mjs:15`).
- **Файл:** `src/data.mjs` (переменная `metrikaId`).
- **Изменение:** Заменить пустое значение на полученный от владельца ID.
- **Зависимости:** ID Метрики от владельца.
- **Риск:** Ошибка в JS при некорректном ID.
- **Откат:** Вернуть `metrikaId: ''`.
- **Критерий приемки:** Вызов `ym` происходит без ошибок, `reachGoal` срабатывает.

### 1.2 Создание и настройка Cloudflare Worker
- **Приоритет:** P0
- **Доказательство:** Файл `worker/lead-worker.mjs` отсутствует в репозитории, форма не может отправить заявку на сервер, а переменная `leadEndpoint` пуста.
- **Файл:** Создать `worker/lead-worker.mjs` и обновить `src/data.mjs` (`leadEndpoint`).
- **Изменение:** Написать код воркера с валидацией CORS, ограничением размера, отправкой в Telegram API. Развернуть и получить URL.
- **Зависимости:** Токен Telegram-бота и Chat ID от владельца.
- **Риск:** Спам-атаки, отказ воркера.
- **Откат:** Очистить `leadEndpoint`, возврат к локальному сохранению (`localStorage`) и уведомлению пользователя звонить напрямую.
- **Критерий приемки:** POST запрос на Endpoint возвращает 200 OK, в Telegram приходит сообщение с заявкой.

### 1.3 Внесение юридических реквизитов
- **Приоритет:** P0
- **Доказательство:** В `src/data.mjs:3-5` стоят заглушки `[ИНН]`, `[ОГРН]`.
- **Файл:** `src/data.mjs` (переменные `legalBrand`, `inn`, `ogrn`).
- **Изменение:** Заменить заглушки на фактические данные.
- **Зависимости:** Данные от владельца.
- **Критерий приемки:** В футере/на юридических страницах отображаются реальные реквизиты.

## 2. P1 (Изменения, значительно улучшающие доверие)

### 2.1 Маркировка/Замена стоковых фотографий
- **Приоритет:** P1
- **Доказательство:** В `data.mjs:35` используются фото `commons.wikimedia.org`. Это вводит пользователей в заблуждение (нарушение доверия).
- **Файл:** `src/data.mjs` (объект `mediaFiles`).
- **Изменение:** Временно добавить подписи "Иллюстративное фото", затем заменить на реальные изображения работ.
- **Зависимости:** Фотографии от владельца.
- **Риск:** Ухудшение визуального стиля, если предоставленные фото будут низкого качества.
- **Откат:** Вернуть ссылки на Wikimedia.
- **Критерий приемки:** В разделе "До / Стало" отображаются реальные фото, загруженные локально (например, `assets/images/real1.jpg`).
