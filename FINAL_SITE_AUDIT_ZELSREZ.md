## 9. Формы — глубокий технический аудит

### Архитектура:
- В шаблонизаторе `src/templates.mjs` используется единая функция-генератор `leadForm(service, options)`.
- Она параметризуется опциями:
  - `withPhoto: true/false`
  - `photoHint: [...]`
  - `commentPlaceholder: '...'`
  - `submitText: '...'`
- В `src/app.js` работает единый инициализатор `initLeadForms()`, обрабатывающий все формы с атрибутом `data-lead-form`.

### Механика отправки и защита:
1. **Защита от дублей (Anti-duplicate lock):**
   ```javascript
   if (form.dataset.submitting === 'true') return;
   form.dataset.submitting = 'true';
   submitBtn.disabled = true;
   submitBtn.textContent = 'Отправляем…';
   ```
   В блоке `finally` флаг сбрасывается, кнопка разблокируется.
2. **Антиспам (Honeypot):**
   Поле `input[name="website"]` скрыто через CSS (`sr-only`, `tabindex="-1"`). Если бот заполняет это поле, отправка тихо прерывается без обращения к API.
3. **Валидация телефона:**
   Нормализация номера через регулярные выражения, отсечение номеров короче 10 цифр с вызовом `reportValidity()`.
4. **Формирование полезной нагрузки (Payload):**
   - Генерируется уникальный `lead_id` вида `lead_172589..._abc123`.
   - Прикрепляются данные первого касания (first-touch UTM и `yclid` из `localStorage`).
   - Фиксируется URL страницы, `entry_page` и название формы.
5. **Транспорт лида (`deliverLead`):**
   - Если прикреплены файлы: отправка через `FormData` (multipart) без ручной установки заголовка `Content-Type` (браузер сам выставляет boundary).
   - Если файлов нет: отправка JSON.
   - Endpoint: Cloudflare Worker `https://zelsrez-leads.roman-k-0b3.workers.dev`.
6. **Резервирование лидов:**
   Каждый лид перед отправкой сохраняется в `localStorage.tree_site_leads_backup` (до 30 последних лидов). При сбое отправки ошибка логируется в `localStorage.tree_site_form_errors`.
